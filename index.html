Belajar GitHub: Menghadapi Kendala Commit dan Push

Catatan pengalaman belajar GitHub bersama tim IT kelas X TKJ ALL di laboratorium komputer.

Hari ini, saya bersama teman-teman dari tim IT kelas X TKJ ALL mencoba melakukan proses commit dan push dari Visual Studio Code (VS Code) ke GitHub. Namun, proses tersebut belum berhasil karena kami menghadapi beberapa kendala, baik dari komputer laboratorium maupun saat proses pendaftaran akun GitHub.

Kendala yang Ditemukan

01 / LABORATORY

Aplikasi Terhapus Setelah Komputer Restart

Pada komputer laboratorium, setiap kali pengguna atau siswa menginstal aplikasi desktop, seperti Adobe Premiere Pro dan aplikasi lainnya, proses instalasi berhasil. Aplikasi tersebut bahkan dapat digunakan seperti biasa. Namun, setelah komputer di-restart, aplikasi yang sebelumnya diinstal justru menghilang.

02 / GITHUB ACCOUNT

Kendala Saat Mendaftar Akun GitHub

Kendala lainnya terjadi pada tahap awal pendaftaran akun GitHub. Kami beberapa kali mencoba melakukan pendaftaran menggunakan alamat IP yang sama dengan jarak waktu percobaan yang sangat singkat. Dalam rentang sekitar tiga detik, saya melakukan klik berulang kali karena proses pendaftaran belum berhasil. Hal ini mungkin berkaitan dengan pembatasan percobaan dari sistem GitHub, meskipun penyebab pastinya belum diketahui.

Catatan Pembelajaran

Dari pengalaman hari ini, saya belajar bahwa proses menggunakan GitHub tidak hanya berkaitan dengan perintah Git seperti commit dan push, tetapi juga membutuhkan kesiapan perangkat komputer dan akun GitHub yang dapat digunakan.
